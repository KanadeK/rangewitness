# Security

Supported version: latest 0.1.x release.

Report vulnerabilities privately through
https://github.com/KanadeK/rangewitness/security/advisories/new .
If private reporting is unavailable, open an issue requesting a private
reporting channel without publishing exploit details or sensitive inputs.
Do not attach private URLs, credentials, traffic, feeds or customer data.

See the README for input bounds and limits of the tool's evidence.
